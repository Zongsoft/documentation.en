# Zongsoft.Collections

`Zongsoft.Collections` provides collection enhancements, hierarchical collections, parameter collections, synchronization collections and common collection extensions, and is the basis for many framework internal object trees and configuration trees.

## Main Responsibilities

* Provides collection types such as classification, hierarchy, parameters, queues, and dictionaries.
* Provides collection events, collection tools, and enumeration extensions.
* Supports common collection scenarios such as logical paths, named collections, synchronous access, and read-only packaging.
